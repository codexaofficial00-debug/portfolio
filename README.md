## 🚀 Features

- **Dark, premium UI** — glassmorphism, gradient accents, and an ambient glow background
- **Animated code-editor hero** — a live typewriter effect showing a C# class introduction
- **Smooth scroll navigation** with a responsive mobile menu
- **Scroll-triggered animations** using the Intersection Observer API
- **Sections:** Hero, About, Skills (with animated progress bars), Projects, Resume/Timeline, and Contact
- **Hover effects** on project cards, buttons, and navigation links
- Fully **responsive** — works on desktop, tablet, and mobile
- Zero dependencies — pure HTML/CSS/JS, deploys anywhere as a static site

## 🛠️ Built With

## 📦 Getting Started

### Run locally
1. Clone this repository
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Open `portfolio.html` directly in your browser — no build step required.

### Deploy on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/root` folder.
4. Save — your site will be live at `https://your-username.github.io/your-repo-name/portfolio.html`
   (rename the file to `index.html` if you want it at the root URL).

### Deploy on Netlify
1. Push this repository to GitHub.
2. Go to [netlify.com](https://netlify.com) → **Add new site → Import an existing project**.
3. Connect your GitHub repo and deploy — no build command needed since it's a static file.

## ✏️ Customization

Before publishing, update the following placeholders in `portfolio.html`:

| Section | What to update |
|---|---|
| Contact | Email address, GitHub link, location |
| Resume | Link the **Download PDF** button to your actual resume file |
| Projects | Replace "Project Two" and "Project Three" with your real projects |
| Form | Connect the contact form to a backend or a service like [Formspree](https://formspree.io/) |
